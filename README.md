# 白金档案b50

个人项目展示与使用帮助。仓库不公开源码、游戏资源或安装包，不提供软件下载。

## 使用帮助

以下命令适用于已配置完成的机器人，支持群聊和私聊。

### 查询 B50

| 模式 | 命令 |
| --- | --- |
| 4k | `/白金b50 4k` |
| 4k+ | `/白金b50 4k+` |
| 6k | `/白金b50 6k` |
| 6k+ | `/白金b50 6k+` |

直接发送 `/白金b50` 默认查询 4k。也支持大写 K，以及 `4`、`4+`、`6`、`6+` 的简写。

### 查看成绩图

- 四种模式的成绩分别统计。
- PLATiNA 与 OTHER 各按 P.A.T.C.H. 从高到低选取前 25 首。
- 每组按从左到右、从上到下排列，各保留 5 行 × 5 列。
- 成绩不足 25 首时，对应位置留空。

### 查询提示

- 默认群聊查询间隔为 30 秒，私聊为 10 秒，具体以机器人配置为准。
- 图片可能使用最近 5 分钟的缓存，请避免连续重复查询。
- 若提示成绩可能不是最新，当前展示的是已保存的历史成绩。
- 没有可用成绩或查询异常时，请联系机器人管理员。
